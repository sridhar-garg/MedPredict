# MedPredict

MedPredict is a Streamlit-based healthcare prediction application
that provides machine-learning-based risk predictions for:

- Heart disease
- Diabetes
- Breast cancer

## Technologies Used

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- SQLite
- Machine Learning

## How to Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
