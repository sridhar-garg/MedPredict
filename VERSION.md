# Version four — Clinical Journal

An independent visual direction on `design/clinical-journal-v4`: warm ivory, forest-green controls, editorial serif headings, a main navigation bar, assessment rows, a health-library column, and a form-first sign-in screen. Existing model, account, report and assessment implementations are preserved.

The Reviews page contains explicitly fictional demo ratings and comments. No real users, clinical outcomes or usage statistics are claimed.

The original image asset is `assets/journal-still-life.webp`, generated using the built-in image generator and optimised locally as WebP. Prompt: premium editorial studio photograph of a silver stethoscope with forest-green tubing on ivory linen, beside a cream notebook, warm daylight and botanical shadow, no people, text, numbers, logos or charts.

Validation: all four branch versions pass Streamlit AppTest checks for Dashboard navigation and the Reviews page, including both feedback tabs, the demo notice and sample metrics. Version four was also inspected in the browser on the dashboard, sign-in screen, Reviews and Real-life usage, including dark mode. Preview images are in `docs/previews/`.
